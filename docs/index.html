Keep catalog entries and personal organization data locally for convenient future access.

Use of the RAWG API

The RAWG API is intended to help users discover games and view game metadata, including titles, descriptions, cover artwork, release dates, genres, ratings, and platform information when available. Search results may be cached locally to improve convenience and reduce repeated requests.

The application uses the API for informational and catalog-organization purposes only. It does not use the API to download, host, or distribute game files or copyrighted game content.
